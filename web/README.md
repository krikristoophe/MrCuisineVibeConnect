# Claudimix — app web/mobile et API

Appli web installable sur téléphone (PWA), tablette et ordinateur, et l'API qui la sert, hébergées
sur Cloudflare (Workers, D1, Durable Objects), sans serveur à maintenir. Le robot (`../android`)
y envoie son état et y lit les repas de la semaine.

Fonctions prévues : suivi du robot à distance, notifications push (cuisson terminée, action
attendue), base de recettes commune initialisée depuis les recettes Lidl et modifiable (dont par MCP),
repas de la semaine du foyer (restes midi → soir, soir → lendemain midi), favoris, connexion Google
uniquement, foyers et ajout du robot par QR code.

Maquettes validées : canevas Claude Design « Claudimix — app web/mobile ».
